# Viikko 5 LLM Chat

Flask + Ollama + MariaDB chat application.

## Features

- Local TinyLlama model
- MariaDB conversation storage
- Nginx reverse proxy
- Gunicorn
- Systemd service
- GitHub Actions CI

## URLs

- /viikko5/
- /viikko5/health

## Technologies

- Python
- Flask
- Ollama
- TinyLlama
- MariaDB
- Nginx
- Gunicorn
- GitHub Actions
